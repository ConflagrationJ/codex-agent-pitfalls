# Codex Agent 踩坑手册

这是构建 Codex Skill、子代理工作流、浏览器扩展和发布管线时留下的现场笔记。它不是 OpenAI 官方文档。很多看起来像“模型不行”的问题，实际是安装位置、生命周期、权限或验证边界的问题。

## 先记住

- 安装成功不等于已经启用。
- 会话启动前安装的 Skill，当前会话不一定看得到。
- 静态测试、mock 行为测试、真实浏览器验证是三种不同的结论。
- 多 Agent 不是越多越好；协调者、写范围、独立复核缺一不可。
- 浏览器自动化要区分“重载扩展”“刷新页面”“后台 service worker 换代”和“弹窗用户激活”。
- 并发权只能有一个来源；互相竞争的文件锁不是事务。
- 不发布私有路径、token、客户数据或未经验证的结论。

## 记录原则

每条经验至少写：现象、根因、最小修复、验证方式、仍未验证的边界。产品规则和上游 schema 永远高于本仓库。
